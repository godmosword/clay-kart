### §4.1 在算繪率低於 24fps 時測不準（Nyquist）

- **輪次**：R28（Lead 驗證時撞到）
- **現況**：這一輪 `§4.1` 量到 **10.087 FAIL**（R26 是 11.846 PASS），
  但**動畫沒有改**——`driver-face.ts` 的量化實作從 R20 起一行沒動
- **原因是取樣定理**：
  ```
  renderedFrames 66、characterAnimationFrames 51 → 每幀 0.773
  fps_p50 14.90，而要解析 12Hz 的訊號必須取樣 > 24Hz
  ```
  算繪率 14.9fps 時每幀最多產生一次格變化，12Hz 的格必然被漏掉。
  這是**量測極限不是動畫缺陷**
- **跟 `§4.2`／`§4.3` 是同一個家族**：指標與算繪速度糾纏在一起，
  FAIL 的理由指錯方向。只是這次發生在低端
- **建議修法**：`§4.1` 需要一個有效性前提——算繪率不足（例如 `fps_p50 < 24`）
  時應該回報「無法解析」而不是一個偏低的數字。跟 `renderedFrames` 那次一樣，
  這不改變窗口，只是讓 FAIL 的理由分得出來
- **注意這條的兩面性**：加了前提之後，在慢機器上 `§4.1` 會變成「未判決」
  而不是 FAIL——那**不能**變成一個永遠不會失敗的檢查。前提要跟
  `§1.1`／`§4.4` 一樣寫明「未判決不是 PASS」
- **狀態**：**切換邏輯已解決並經 Lead 驗證（R33），窗口另開新條**。
  `fps_p05 > 24` 走 hz、否則走 ratio、缺值走 `MISSING` → FAIL，
  上面擔心的兩面性沒有發生。**但 ratio 模式的窗口 `[0, 0.95]` 本身在適用
  範圍外會誤判**，見上方「`§4.1` 的 ratio 窗口在適用範圍外會誤判」那條

- **輪次**：R20（接線時發現）
- **現況**：`src/ui/player-input.ts` 把 `ArrowRight`／`KeyD` 對到 `steer = +1`；
  `src/physics/world.ts` 的 `yawRate = steeringInput * MAX_STEER_YAW_RATE * …`

  等於車頭從 `+Z` 轉向 `+X`。追尾相機沿 `+forward` 看出去時，**`+X` 在畫面
  左側**（相機 local X = `(-fz, 0, fx)`，yaw=0 時等於 `(-1,0,0)`）。

### 黏土管線的效能成本：VSM 陰影是主導項

- **輪次**：R20
- **現況**：同機器同 probe 三種設定（artifacts 三份 JSON 可覆核）：

  | W1 方塊車 | 51.81 | 39.8ms | 5 | 3.3 |

  材質與幾何本身約 3.7×，**VSM 陰影再 12×**。主導成本是陰影，不是材質
- **量測環境的限制（重要）**：容器內 SwiftShader 軟體算繪，沒有 GPU。
  同一支 probe 在這台機器上量 W1 方塊車只有 51.8fps，R19 在原本的機器上量到
  59.88fps —— **跨機器絕對值不可比，只有同機器相對值可比**。所以「1.17fps」
  不等於「遊戲在目標裝置上是 1.17fps」，但「陰影佔了 12 倍」這個比例是可信的
- **目標**：`BAR-PERF §2` 全項回到窗口內
- **已處理（R20 後續）：陰影參數掃描，採用 512/4。** 同機器同 probe：

  | 貼圖 / 取樣 | fps_p50 | 畫面差異 |
  |---|---|---|
  | 2048 / 16（R18 原設定） | 約 0.8–1.2 | 基準 |
  | 1024 / 8 | 3.19 | 看不出來 |
  | **512 / 4（採用）** | **約 6.3** | 看不出來 |
  | 陰影全關（上限參考） | 14.01 | 失去自體遮蔽 |

  並排截圖與三份 artifact 在 `loop/round-20/artifacts/shadow-sweep/`。

  frustum 除以 512 仍有約 3.5cm/texel——貼圖解析度是拿來換銳利度的，而 `§5.0`
  明文不要銳利。重複性：同設定連跑三次 `fps_p50` 為 6.25／5.87／6.85（±8%），
  倍率差異遠大於雜訊；但 `fps_p05` 與 `frame_time_p99` 在這個環境雜訊很大
  （低幀率下取樣數太少），不適合拿來比較設定
- **仍未解決的部分**：即時投影就算調到 512/4 仍佔掉一半以上的幀時間
  （6.3 vs 關掉的 14.0）。`§5.0` 對接地陰影的規格是「短、柔、低對比，落在
  物件正下方略偏前」——那描述的東西**一張貼片就做得到**。真正會失去的是
  自體遮蔽（車底、輪拱、接縫那圈暗），也就是 `§5.0` 的 AO 條款來源。
  所以這不是純效能取捨，是「用貼片換掉自體遮蔽划不划算」，得看得到兩種做法
  的並排圖才能判斷
